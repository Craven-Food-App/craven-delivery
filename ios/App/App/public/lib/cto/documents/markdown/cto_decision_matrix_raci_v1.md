## 1. Purpose Of This Matrix

Defines decision-making authority for CTO and cross-functional executives. Ensures alignment, accountability, and clarity at scale.

---

## 2. RACI Legend

**D – Decision Authority:** Final decision power  

**A – Accountable:** Owns the outcome  

**R – Responsible:** Performs the work  

**C – Consulted:** Provides input  

**I – Informed:** Updated afterward

## 4. Rules Of Engagement

### CTO Must Escalate To CEO When:

- System downtime or performance materially deviates  

- Security breach or vulnerability risk emerges  

- Infrastructure cost exposure identified  

- A decision impacts multiple departments  

### CTO Independent Authority Includes:

- Engineering standards  

- System architecture  

- Security controls  

- Technology tool selection  

- Infrastructure provisioning
