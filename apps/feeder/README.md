# Crave'n Feeder (Android / iOS)

Capacitor native shell for the Feeder driver app. **All driver UI, Clean Pay, and earnings logic live in the repo-root `src/` tree** — this app does not maintain a separate feature codebase.

## Architecture

| Path | Role |
|------|------|
| `apps/feeder/src/main.tsx` | Entry + routes (`MobileDriverDashboard`, auth, onboarding) |
| `apps/feeder/vite.config.ts` | `@` → `../../src` (root source) |
| `../../dist` | Vite build output (`webDir` for Capacitor) |
| `android/`, `ios/` | Native projects (`cap sync`) |

## Features (implemented in root `src/`)

- **Clean Pay** — `src/lib/feederCleanPaySummary.ts`, `FeederCleanPayCard`, RPCs via Supabase
- **Active delivery** — `CravenDeliveryFlow.tsx` (stage summaries, pickup sync, compact card)
- **Order complete** — `FeederOrderCompleteScreen`, receipt + order-details modals
- **Offers / retail / batch** — `MobileDriverDashboard.tsx`, `RetailGroceryOfferFlow`, `RetailGroceryPickupFlow`
- **Earnings → Delivery History** — `EarningsDashboard.tsx` (filters, search, grouping, Clean Pay detail on tap)

## Build & run on device

From repo root:

```bash
npm run feeder:build          # Vite build + cap sync android
npm run feeder:build:android  # Full Android release build
npm run feeder:open:android   # Open Android Studio
npm run feeder:open:ios       # Open Xcode
```

Dev server (browser / live reload):

```bash
cd apps/feeder && npm run dev
```

After pulling Clean Pay or earnings changes, **rebuild** so native bundles are not stale (`ios/App/App/public` is generated by `cap sync`, not hand-edited).
