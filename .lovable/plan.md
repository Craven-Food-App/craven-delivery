

# Firebase Cloud Messaging (FCM) for Feeder Android App

## Problem
The Feeder app currently only shows in-app toasts with no sound. There are no native Android notifications, so drivers miss critical alerts when the app is backgrounded or closed.

## What Already Exists
- Capacitor Push Notifications plugin is installed and wired in the Android build
- Frontend code (`PushNotificationSetup.tsx`) already registers FCM tokens and sends them to the backend
- `push_subscriptions` table has `is_native` and `push_token` columns
- `FIREBASE_SERVER_KEY` and `FIREBASE_SERVICE_ACCOUNT_KEY` secrets are already configured
- `google-services.json` check exists in `build.gradle` but the file itself is missing

## What's Missing
1. **`google-services.json`** file in `apps/feeder/android/app/` -- without this, FCM cannot initialize
2. **Backend FCM delivery** -- the `send-push-notification` edge function only does raw web push `fetch()` to endpoints. It never uses the Firebase API to send to native FCM tokens
3. **`driver_push_subscriptions` table lacks native columns** -- no `is_native`, `push_token`, or `is_active` columns (the `send-push-notification` function queries this table, not `push_subscriptions`)
4. **No notification channel** configured in Android for sound/vibration

## Plan

### Step 1: You Provide `google-services.json`
You need to download `google-services.json` from the Firebase Console for your `com.craven.delivery.feeder` project and place it at `apps/feeder/android/app/google-services.json`. **This file is project-specific and cannot be generated by Lovable.**

How to get it:
1. Go to [Firebase Console](https://console.firebase.google.com)
2. Select your project (or create one)
3. Go to Project Settings (gear icon)
4. Under "Your apps", add an Android app with package name `com.craven.delivery.feeder`
5. Download `google-services.json`
6. Place it in `apps/feeder/android/app/`

### Step 2: Add Native Columns to `driver_push_subscriptions`
Create a migration to add `is_active`, `is_native`, and `push_token` columns to the `driver_push_subscriptions` table so the backend can distinguish native FCM subscriptions from web push ones.

### Step 3: Rewrite `send-push-notification` Edge Function
Replace the raw `fetch()` approach with Firebase Cloud Messaging HTTP v1 API calls for native subscriptions:
- For subscriptions where `is_native = true`, send via FCM using the `FIREBASE_SERVICE_ACCOUNT_KEY` to get an OAuth2 token and POST to `https://fcm.googleapis.com/v1/projects/{project}/messages:send`
- For web push subscriptions, keep the existing VAPID web push logic
- Set high priority, sound, and notification channel so Android shows the notification even when the app is closed

### Step 4: Update `register-push-subscription` Edge Function
Modify the function to also upsert into `driver_push_subscriptions` (not just `push_subscriptions`) when the user is a driver, storing the FCM token and native flag.

### Step 5: Configure Android Notification Channel
Update the Feeder's `capacitor.config.ts` to include a default notification channel with sound and importance set to high, and update `AndroidManifest.xml` to declare a default FCM notification channel with the Crave'N notification sound.

### Step 6: Add Firebase Messaging Service
Create a custom `FirebaseMessagingService` Java class in the Feeder Android app that handles incoming messages when the app is in the background/killed, plays the notification sound, and shows a system notification.

## Technical Details

### Migration SQL
```sql
ALTER TABLE public.driver_push_subscriptions
  ADD COLUMN IF NOT EXISTS is_active BOOLEAN NOT NULL DEFAULT true,
  ADD COLUMN IF NOT EXISTS is_native BOOLEAN NOT NULL DEFAULT false,
  ADD COLUMN IF NOT EXISTS push_token TEXT;
```

### FCM HTTP v1 API Call (in edge function)
```typescript
// Get OAuth2 access token from service account
const serviceAccount = JSON.parse(Deno.env.get("FIREBASE_SERVICE_ACCOUNT_KEY"));
// ... JWT signing to get access token ...

// Send FCM message
await fetch(
  `https://fcm.googleapis.com/v1/projects/${serviceAccount.project_id}/messages:send`,
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${accessToken}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      message: {
        token: pushToken,
        notification: { title, body },
        android: {
          priority: "high",
          notification: {
            sound: "default",
            channel_id: "craven_orders",
          },
        },
      },
    }),
  }
);
```

### AndroidManifest.xml additions
```xml
<meta-data
    android:name="com.google.firebase.messaging.default_notification_channel_id"
    android:value="craven_orders" />
<meta-data
    android:name="com.google.firebase.messaging.default_notification_icon"
    android:resource="@mipmap/ic_launcher" />
```
