## 📖 How to Use SOPs

### Reading an SOP:
1. Review the **Purpose** section
2. Check **Prerequisites**
3. Follow **Procedure** step-by-step
4. Use **Checklists** to track progress
5. Refer to **Troubleshooting** if issues arise

### Following an SOP:
- Read completely before starting
- Gather required materials
- Follow steps in order
- Document completion
- Report issues or improvements

### Updating an SOP:
- Submit change request to HR
- Include rationale for change
- Await approval
- Changes communicated to all users
