# SOP-008: Manager's Guide to Intern Portal

**Document ID:** SOP-INTERN-008  
**Version:** 1.0  
**Effective Date:** December 18, 2025  
**Department:** Human Resources  
**Process Owner:** Hiring Manager  
**Review Frequency:** Quarterly  

---

## 1. PURPOSE

Provide comprehensive guidance for managers on using the Manager Portal to effectively supervise and support interns.

---

## 2. ACCESSING THE MANAGER PORTAL

1. Log in to cravenusa.com
2. Navigate to **Manager Portal** from main menu
3. Or go directly to: cravenusa.com/manager

**Required Role:** Manager, Department Head, or Executive

---

## 3. DASHBOARD OVERVIEW

### Key Metrics Displayed

**My Interns Summary:**
- Total active interns
- Tasks in progress
- Tasks overdue
- Pending approvals
- Upcoming evaluations

**Quick Actions:**
- Assign new task
- Approve time log
- Schedule evaluation
- View reports

---

## 4. MANAGING INTERNS

### View Intern List

1. Navigate to **My Interns**
2. See all interns you manage
3. View key info:
   - Name
   - Role track
   - Start date
   - Days completed
   - Performance score
   - Status

### View Intern Profile

1. Click on intern name
2. See complete profile:
   - Contact information
   - Program details
   - Manager & mentor
   - Learning plan
   - Performance history

**Tabs Available:**
- Overview
- Tasks
- Deliverables
- Time Logs
- Evaluations
- Goals
- Feedback
- Documents

---

## 5. TASK MANAGEMENT

### Assign New Task

1. Navigate to **My Interns** > [Intern Name] > **Tasks**
2. Click **Assign New Task**
3. Fill out form (see SOP-INTERN-003)
4. Click **Assign**

### Monitor Task Progress

1. View **Tasks** dashboard
2. Filter by:
   - Status (In Progress, Blocked, Overdue)
   - Priority
   - Due date
   - Intern

3. Take action on issues

### Review Deliverables

1. Navigate to **Deliverables** > **Pending Review**
2. Click on deliverable
3. Review work
4. Provide feedback
5. Approve or request changes

---

## 6. TIME LOG MANAGEMENT

### Review Time Logs

1. Navigate to **Time Logs** > **Pending Approval**
2. Review each log:
   - Date
   - Hours
   - Task
   - Description

3. Verify accuracy

### Approve Time Logs

1. Select logs to approve
2. Click **Approve Selected**
3. Or approve individually

### Request Corrections

1. Click **Request Correction**
2. Explain issue
3. Intern revises and resubmits

**Best Practice:** Approve weekly, don't let them pile up

---

## 7. EVALUATIONS

### Create Evaluation

1. Navigate to **Evaluations** > **Create New**
2. Select evaluation type:
   - Onboarding (Day 14)
   - Mid-Term (Day 45)
   - Final (Day 90)
   - Quarterly
   - Ad-Hoc

3. Complete evaluation form (see SOP-INTERN-004)
4. Submit

### View Evaluation History

1. Navigate to **Evaluations** > **History**
2. See all past evaluations
3. Track progress over time

---

## 8. FEEDBACK & COMMUNICATION

### Provide Feedback

1. Navigate to **Feedback** > **Give Feedback**
2. Select intern
3. Choose feedback type:
   - Positive
   - Constructive
   - General

4. Write feedback
5. Choose visibility (private or shared)
6. Submit

### View Feedback History

1. Navigate to **Feedback** > **History**
2. See all feedback given
3. Track patterns

---

## 9. CONVERSION MANAGEMENT

### Initiate Conversion

1. Navigate to **Conversion Pathway**
2. Select intern
3. Click **Initiate Conversion**
4. System shows eligibility status
5. Complete conversion form
6. Submit for approval

### Track Conversion Status

1. View conversion pipeline
2. See approval status
3. Take action if needed

---

## 10. REPORTS & ANALYTICS

### Available Reports

**Intern Performance Report:**
- Individual performance metrics
- Task completion rates
- Time tracking summary
- Evaluation scores

**Team Overview Report:**
- All interns summary
- Comparative performance
- Program completion status

**Time Tracking Report:**
- Hours logged by intern
- Hours by task type
- Approval status

**Task Management Report:**
- Tasks assigned
- Completion rates
- Overdue tasks
- Blocked tasks

### Generate Report

1. Navigate to **Reports**
2. Select report type
3. Choose date range
4. Select interns (or all)
5. Click **Generate**
6. Export as PDF or Excel

---

## 11. BEST PRACTICES

### Daily Tasks (5-10 minutes)
- Check dashboard for alerts
- Review new deliverables
- Respond to intern questions
- Unblock blocked tasks

### Weekly Tasks (30-60 minutes)
- Approve time logs
- Review task progress
- Assign new tasks
- Provide feedback
- Hold 1:1 meetings

### Monthly Tasks (1-2 hours)
- Review performance metrics
- Conduct evaluations (if due)
- Update learning plans
- Plan next month's work

## 13. NOTIFICATIONS

**You'll receive notifications for:**
- New deliverable submitted
- Task overdue
- Time log pending approval
- Evaluation due
- Intern needs help (blocked task)
- Conversion milestone reached

**Notification Settings:**
- Email: Immediate, Daily Digest, or Off
- In-App: Always on
- SMS: Optional for urgent items

**Configure:**
1. Navigate to **Settings** > **Notifications**
2. Choose preferences
3. Save

---

## 14. TROUBLESHOOTING

| Issue | Solution |
|-------|----------|
| Can't see intern | Verify you're assigned as manager in system |
| Can't assign task | Check permissions, contact HR if issue persists |
| Time log won't approve | Check for errors, may need correction |
| Report won't generate | Try different date range, contact IT if persists |
| Notification not received | Check spam folder, verify notification settings |
