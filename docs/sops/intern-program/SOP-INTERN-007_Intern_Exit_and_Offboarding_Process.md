# Intern Exit & Offboarding Process

**Document ID:** SOP-INTERN-007  
**Version:** 1.0  
**Effective Date:** December 18, 2025  
**Department:** Human Resources  
**Process Owner:** HR Coordinator  
**Review Frequency:** Quarterly  

---

## 1. PURPOSE

Define the process for smoothly transitioning interns out of the program, whether due to program completion, conversion to FTE, or early exit.

---

## 2. EXIT TYPES

| Exit Type | Description | Process |
|-----------|-------------|---------|
| **Program Completion** | Successful completion of internship | Standard offboarding |
| **Conversion to FTE** | Transitioning to full-time employee | See SOP-INTERN-006 |
| **Resignation** | Intern chooses to leave early | Early exit process |
| **Termination** | Involuntary separation | Immediate exit process |

---

## 3. TIMELINE

**Standard Program Completion:**
```
Day -14: Exit process initiated
Day -7:  Exit interview scheduled
Day -3:  Asset return reminder
Day 0:   Last day, final tasks
Day +1:  Access revoked
Day +7:  Final documentation complete
```

---

## 4. PROCEDURE

### PHASE 1: PRE-EXIT (14 Days Before Last Day)

#### Step 1.1: Initiate Exit Process

**Who:** HR Coordinator  
**When:** 14 days before last day  
**Time:** 15 minutes

1. Log in to HR Portal
2. Navigate to **Intern Program** > [Intern Name]
3. Click **Initiate Offboarding**
4. Select exit type:
   - Program Completion
   - Conversion to FTE
   - Resignation
   - Termination

5. System automatically:
   - Creates offboarding checklist
   - Notifies manager
   - Notifies IT
   - Schedules exit interview
   - Sends exit instructions to intern

---

#### Step 1.2: Manager Notification

**Who:** Manager  
**When:** Upon notification  
**Time:** 30 minutes

**Manager Actions:**
1. Review exit notification
2. Plan knowledge transfer:
   - Document current projects
   - Identify handoff needs
   - Schedule transition meetings

3. Prepare final evaluation (if not done)

4. Plan last day activities:
   - Team goodbye
   - Final 1:1
   - Celebration (optional)

---

#### Step 1.3: Knowledge Transfer

**Who:** Intern + Manager  
**When:** Days -14 to -1  
**Time:** Varies

**Intern Responsibilities:**
1. Document all current work:
   - Project status
   - Code/files locations
   - Passwords/access (to be transferred)
   - Pending tasks
   - Important contacts

2. Create handoff document:
   - What's in progress
   - What's completed
   - What's pending
   - Recommendations

3. Train replacement (if applicable)

4. Complete all assigned tasks or document status

---

### PHASE 2: EXIT INTERVIEW (7 Days Before)

#### Step 2.1: Schedule Exit Interview

**Who:** HR Coordinator  
**When:** 7 days before last day  
**Time:** 45 minutes

**Exit Interview Questions:**

**Program Experience:**
1. Overall, how would you rate your internship experience? (1-5)
2. What were the highlights of your internship?
3. What were the biggest challenges?
4. Did the internship meet your expectations?

**Learning & Development:**
5. What skills did you develop?
6. What did you learn about the industry/company?
7. Were learning opportunities adequate?
8. What additional training would have been helpful?

**Management & Support:**
9. How would you rate your manager's support? (1-5)
10. Did you receive adequate feedback?
11. Was your mentor helpful?
12. Did you feel valued as a team member?

**Work Environment:**
13. How would you describe the company culture?
14. Did you feel included and respected?
15. Was the workload appropriate?
16. Were resources adequate?

**Future Plans:**
17. What are your next steps?
18. Would you consider returning to Crave'n?
19. Would you recommend our internship program?
20. Any suggestions for improvement?

**Final Thoughts:**
21. Is there anything else you'd like to share?
22. Can we use you as a reference for future candidates?
23. Would you like to join our alumni network?

---

#### Step 2.2: Document Feedback

**Who:** HR Coordinator  
**When:** During/after exit interview  
**Time:** 15 minutes

1. Record responses in system
2. Flag any concerns for leadership
3. Identify improvement opportunities
4. Add to program metrics

---

### PHASE 3: ASSET RETURN (3 Days Before)

#### Step 3.1: Asset Return Checklist

**Who:** Intern + IT  
**When:** 3 days before last day  
**Time:** 30 minutes

**Items to Return:**
- [ ] Laptop
- [ ] Monitor, keyboard, mouse
- [ ] Headset
- [ ] Access badge
- [ ] Building keys
- [ ] Company credit card (if issued)
- [ ] Any company materials/documents
- [ ] Other equipment: ___________

**Return Process:**
1. Intern brings items to IT/HR
2. IT verifies condition
3. IT signs off on return
4. Items logged in system

**If Remote:**
1. Intern ships items via provided label
2. IT confirms receipt
3. IT verifies condition

---

#### Step 3.2: Data & File Transfer

**Who:** Intern + IT  
**When:** 3 days before last day  
**Time:** 1 hour

**Intern Actions:**
1. Transfer all work files to designated location
2. Delete personal files from company devices
3. Clear browser history/saved passwords
4. Remove personal accounts from company devices

**IT Actions:**
1. Backup intern's work files
2. Transfer files to manager
3. Wipe company devices
4. Verify no company data on personal devices

---

### PHASE 4: LAST DAY (Day 0)

#### Step 4.1: Final Tasks

**Who:** Intern  
**When:** Last day  
**Time:** Varies

**Morning:**
1. Complete any final work
2. Finalize handoff documentation
3. Send goodbye emails (if desired)
4. Return any remaining items

**Afternoon:**
1. Final 1:1 with manager
2. Team goodbye/celebration
3. HR exit meeting
4. Return badge/equipment

---

#### Step 4.2: Final Manager Meeting

**Who:** Manager + Intern  
**When:** Last day, afternoon  
**Time:** 30 minutes

**Discussion Topics:**
1. Thank intern for contributions
2. Highlight accomplishments
3. Provide final feedback
4. Offer to be reference
5. Discuss staying in touch
6. Provide recommendation letter (if requested)
7. Invite to alumni network

**Manager Provides:**
- Letter of recommendation (if requested)
- LinkedIn recommendation (if appropriate)
- Contact information for future reference

---

#### Step 4.3: HR Exit Meeting

**Who:** HR Coordinator + Intern  
**When:** Last day, end of day  
**Time:** 30 minutes

**HR Checklist:**
- [ ] Exit interview completed
- [ ] All assets returned
- [ ] Final timesheet submitted and approved
- [ ] Final paycheck information provided
- [ ] COBRA information provided (if applicable)
- [ ] 401(k) rollover information (if applicable)
- [ ] Academic credit documentation finalized (if applicable)
- [ ] Alumni network invitation sent
- [ ] Certificate of completion provided

**Provide Intern:**
- Certificate of Completion
- Final pay information
- Benefits termination info
- Reference letter (if requested)
- Alumni network info
- Exit survey link

---

### PHASE 5: POST-EXIT (After Last Day)

#### Step 5.1: Access Revocation

**Who:** IT Administrator  
**When:** End of last day or next business day  
**Time:** 15 minutes

**Revoke Access:**
- [ ] Email account (forward to manager for 30 days)
- [ ] Slack/Teams
- [ ] GitHub/code repositories
- [ ] Project management tools
- [ ] Design tools
- [ ] VPN access
- [ ] Building access
- [ ] Any other systems

**Timeline:**
- Email: Forward for 30 days, then disable
- Other systems: Disable immediately
- Building access: Deactivate end of last day

---

#### Step 5.2: Final Documentation

**Who:** HR Coordinator  
**When:** Within 7 days of last day  
**Time:** 30 minutes

**Complete:**
1. Final evaluation (if not done)
2. Exit interview summary
3. Asset return confirmation
4. Final timesheet approval
5. Update intern record:
   - Mark as "Completed"
   - Add exit date
   - Add exit type
   - Add exit notes

6. File all documents:
   - Offer letter
   - Evaluations
   - Time logs
   - Exit interview
   - Asset return form
   - Academic credit docs (if applicable)

---

#### Step 5.3: Alumni Network

**Who:** HR Coordinator  
**When:** Within 7 days of last day  
**Time:** 10 minutes

1. Add intern to alumni database
2. Send alumni network invitation:
   - LinkedIn group
   - Email list
   - Slack alumni channel (if exists)

3. Provide alumni benefits:
   - Job postings
   - Networking events
   - Referral bonuses
   - Boomerang program info

---

## 5. EARLY EXIT PROCESS

### Voluntary Resignation

**If intern resigns before program end:**

1. Accept resignation professionally
2. Determine last day (typically 2 weeks notice)
3. Initiate standard exit process
4. Conduct exit interview to understand reasons
5. Maintain positive relationship

**Manager Actions:**
- Don't take it personally
- Wish them well
- Offer to stay in touch
- Provide reference if appropriate

---

### Involuntary Termination

**If intern must be terminated:**

1. Consult with HR and legal before action
2. Document performance issues
3. Ensure termination is justified
4. Plan termination meeting
5. Have HR present
6. Be respectful and professional
7. Immediate access revocation
8. Immediate asset return
9. Provide final pay information
10. Document everything

**Termination Meeting:**
- Brief and professional
- State decision clearly
- Don't argue or debate
- Provide final pay info
- Collect assets immediately
- Escort from building (if on-site)

## 8. METRICS & REPORTING

**Track:**
- Exit interview completion rate (target: 100%)
- Program completion rate (target: 90%+)
- Early exit rate (target: < 10%)
- Would recommend rate (target: 90%+)
- Would return rate (target: 80%+)
- Asset return rate (target: 100%)

**Analyze:**
- Exit reasons
- Common feedback themes
- Areas for improvement
- Manager performance
- Program effectiveness

## 10. TROUBLESHOOTING

| Issue | Solution |
|-------|----------|
| Intern won't return assets | Withhold final pay until returned, legal action if needed |
| Negative exit interview | Thank for feedback, investigate concerns, improve program |
| Intern wants to extend program | Assess business need, check eligibility, extend if appropriate |
| Manager upset about exit | Remind it's normal, focus on knowledge transfer |
| Intern wants to leave early | Allow if possible, maintain positive relationship |
