# SOP-002: New Intern Onboarding (Day 1-30)

**Document ID:** SOP-INTERN-002  
**Version:** 1.0  
**Effective Date:** December 18, 2025  
**Department:** Human Resources  
**Process Owner:** HR Coordinator  
**Review Frequency:** Quarterly  

---

## 1. PURPOSE

This SOP defines the step-by-step process for onboarding new interns into the Crave'n Intern Program, from offer acceptance through the first 30 days.

---

## 2. SCOPE

**Applies to:**
- HR Coordinators
- Hiring Managers
- IT Administrators
- Department Heads
- Executive Sponsors

**Covers:**
- Pre-arrival preparation
- First day onboarding
- First week activities
- First month milestones
- Onboarding evaluation

---

## 3. TIMELINE OVERVIEW

```
Day -7 to -1:  Pre-Arrival Preparation
Day 0:         First Day Onboarding
Days 1-5:      First Week Activities
Days 6-14:     Onboarding Evaluation Period
Days 15-30:    Integration & First Projects
```

---

## 4. RESPONSIBILITIES

| Role | Responsibility |
|------|----------------|
| **HR Coordinator** | Coordinate entire onboarding process, ensure compliance |
| **Hiring Manager** | Prepare workspace, assign mentor, create initial tasks |
| **IT Administrator** | Set up accounts, provide equipment |
| **Executive Sponsor** | Welcome intern, provide strategic context |
| **Mentor/Buddy** | Guide intern day-to-day, answer questions |

---

## 5. PREREQUISITES

Before starting onboarding:
- [ ] Intern has accepted offer letter
- [ ] Background check completed (if required)
- [ ] I-9 verification completed
- [ ] Start date confirmed
- [ ] Role track assigned
- [ ] Manager assigned
- [ ] Mentor assigned
- [ ] Workspace/equipment identified

---

## 6. PROCEDURE

### PHASE 1: PRE-ARRIVAL PREPARATION (Days -7 to -1)

#### Step 1.1: Create Intern Profile in System

**Who:** HR Coordinator  
**When:** 7 days before start date  
**Time:** 15 minutes

1. Log in to HR Portal
2. Navigate to **Intern Program Admin** > **Interns Table**
3. Click **Add New Intern**
4. Enter intern information:
   ```
   Full Name: [First Last]
   Email: [intern.name]@cravenusa.com
   Personal Email: [provided in application]
   Phone: [provided]
   Start Date: [confirmed date]
   End Date: [start date + program duration]
   Role Track: [Engineering/Operations/etc.]
   Department: [assigned department]
   Manager: [select from dropdown]
   Mentor: [select from dropdown]
   Executive Sponsor: [select if applicable]
   Work Schedule: [Full-time/Part-time]
   Hours Per Week: [10-40]
   Academic Credit: [Yes/No]
   Institution: [if applicable]
   ```

5. Click **Create Intern Profile**
6. System automatically:
   - Generates employee ID
   - Creates user account
   - Sends welcome email to intern
   - Notifies manager and mentor
   - Creates onboarding checklist

**Expected Result:** Intern profile created, welcome email sent

---

#### Step 1.2: Set Up IT Accounts & Equipment

**Who:** IT Administrator  
**When:** 5 days before start date  
**Time:** 30 minutes

1. Receive notification from HR system
2. Create accounts:
   - [ ] Email account: [intern.name]@cravenusa.com
   - [ ] Slack/Teams account
   - [ ] GitHub account (for engineering)
   - [ ] Supabase access (if needed)
   - [ ] Design tools (if needed)
   - [ ] Project management tools (Jira, Asana, etc.)

3. Prepare equipment:
   - [ ] Laptop (if on-site)
   - [ ] Monitor, keyboard, mouse
   - [ ] Headset
   - [ ] Access badge
   - [ ] Company swag (t-shirt, notebook, etc.)

4. Set up workspace:
   - [ ] Assign desk/workspace
   - [ ] Set up computer
   - [ ] Test all accounts
   - [ ] Prepare welcome packet

5. Send credentials to intern:
   - Email login instructions
   - Include IT support contact
   - Schedule tech setup call (if remote)

**Expected Result:** All accounts created, equipment ready

---

#### Step 1.3: Manager Prepares Onboarding Plan

**Who:** Hiring Manager  
**When:** 5 days before start date  
**Time:** 1 hour

1. Log in to Manager Portal
2. Navigate to **My Interns** > [Intern Name]
3. Click **Onboarding Plan** tab
4. Create first week schedule:

**Day 1 Schedule:**
```
9:00 AM  - Welcome & Office Tour
9:30 AM  - IT Setup & Account Access
10:30 AM - Meet the Team
11:00 AM - Company Overview Presentation
12:00 PM - Lunch with Mentor
1:00 PM  - Department Overview
2:00 PM  - Review Role Track & Learning Plan
3:00 PM  - Set Up Development Environment (if technical)
4:00 PM  - First Day Wrap-Up & Q&A
5:00 PM  - End of Day 1
```

5. Create initial tasks:
   - Click **Assign Task**
   - Create 3-5 onboarding tasks:
     ```
     Task 1: Complete Company Culture Training (Day 1)
     Task 2: Read Employee Handbook (Day 2)
     Task 3: Complete Security Training (Day 3)
     Task 4: Shadow team member (Days 3-5)
     Task 5: Complete first small project (Week 2)
     ```

6. Assign mentor:
   - Select mentor from team
   - Send mentor onboarding guide
   - Schedule mentor/intern intro call

7. Prepare welcome message:
   - Write personalized welcome email
   - Include team intro
   - Share first week agenda
   - Provide parking/building access info

8. Click **Save Onboarding Plan**

**Expected Result:** First week planned, tasks created, mentor assigned

---

#### Step 1.4: Send Pre-Arrival Welcome Package

**Who:** HR Coordinator  
**When:** 3 days before start date  
**Time:** 15 minutes

1. Compile welcome package:
   - Welcome letter from CEO
   - Employee handbook
   - Intern program guide
   - First day agenda
   - Parking/building access instructions
   - Team directory
   - Company org chart
   - Benefits information
   - IT setup instructions

2. Send via email with subject: "Welcome to Crave'n! Your First Day Guide"

3. Include in email:
   ```
   Hi [Intern Name],

   We're excited to welcome you to Crave'n on [Start Date]!

   Attached is your welcome package with everything you need to know
   for your first day and first week.

   First Day Details:
   - Date: [Start Date]
   - Time: 9:00 AM
   - Location: [Address or Zoom link]
   - Your Manager: [Manager Name] - [manager.email]@cravenusa.com
   - Your Mentor: [Mentor Name] - [mentor.email]@cravenusa.com

   What to Bring:
   - Photo ID (for I-9 verification)
   - Completed tax forms (attached)
   - Laptop (if you have one, otherwise we'll provide)
   - Questions!

   If you have any questions before your start date, please don't
   hesitate to reach out.

   See you soon!

   [HR Coordinator Name]
   Human Resources
   hr@cravenusa.com
   ```

4. Log email sent in intern profile

**Expected Result:** Intern receives welcome package and first day details

---

### PHASE 2: FIRST DAY ONBOARDING (Day 0)

#### Step 2.1: Welcome & Check-In

**Who:** HR Coordinator  
**When:** Day 1, 9:00 AM  
**Time:** 30 minutes

1. Greet intern at reception/Zoom
2. Complete I-9 verification (if not done)
3. Collect signed documents:
   - [ ] Offer letter
   - [ ] Confidentiality agreement
   - [ ] Code of conduct
   - [ ] IT acceptable use policy
   - [ ] Academic learning agreement (if applicable)

4. Provide:
   - [ ] Employee badge
   - [ ] Building access card
   - [ ] Parking pass
   - [ ] Company swag

5. Give office tour (if on-site):
   - Workspace
   - Restrooms
   - Kitchen/break room
   - Conference rooms
   - Emergency exits

6. Introduce to reception/admin staff

**Expected Result:** Intern feels welcomed, paperwork complete

---

#### Step 2.2: IT Setup & Account Access

**Who:** IT Administrator  
**When:** Day 1, 9:30 AM  
**Time:** 45 minutes

1. Meet with intern (in-person or video call)
2. Set up computer:
   - [ ] Log in to laptop
   - [ ] Set up email
   - [ ] Install required software
   - [ ] Configure VPN (if remote)
   - [ ] Test all applications

3. Walk through key systems:
   - Email & calendar
   - Slack/Teams
   - Project management tools
   - Time tracking system
   - Document storage
   - Intern portal

4. Provide IT support information:
   - Help desk email
   - Help desk phone
   - IT Slack channel
   - Self-service portal

5. Have intern log in to Intern Portal:
   - Navigate to cravenusa.com/intern
   - Log in with credentials
   - Verify access to:
     - Dashboard
     - Tasks
     - Time logs
     - Learning modules
     - Documents

**Expected Result:** All systems accessible and working

---

#### Step 2.3: Meet the Team

**Who:** Hiring Manager  
**When:** Day 1, 10:30 AM  
**Time:** 30 minutes

1. Introduce intern to immediate team
2. For each team member:
   - Name and role
   - What they work on
   - How intern will interact with them

3. Team icebreaker activity (optional):
   - Two truths and a lie
   - Fun fact sharing
   - Quick team game

4. Explain team communication norms:
   - Daily standup time
   - Slack channels to join
   - Meeting schedules
   - How to ask for help

5. Add intern to team channels:
   - [ ] Team Slack channel
   - [ ] Department channel
   - [ ] Social channel
   - [ ] Announcements channel

**Expected Result:** Intern knows team members and communication norms

---

#### Step 2.4: Company Overview Presentation

**Who:** HR Coordinator or Executive  
**When:** Day 1, 11:00 AM  
**Time:** 45 minutes

**Presentation Topics:**
1. Company History & Mission
   - How Crave'n started
   - Mission, vision, values
   - Growth trajectory

2. Business Model
   - How we make money
   - Customer segments
   - Competitive advantages

3. Company Culture
   - Core values in action
   - Communication style
   - Work-life balance
   - Diversity & inclusion

4. Organizational Structure
   - Departments overview
   - Leadership team
   - How departments work together

5. Intern Program Overview
   - Program goals
   - What success looks like
   - Conversion opportunities
   - Support resources

6. Q&A

**Expected Result:** Intern understands company and program

---

#### Step 2.5: Lunch with Mentor

**Who:** Assigned Mentor  
**When:** Day 1, 12:00 PM  
**Time:** 1 hour

**Mentor's Goals:**
1. Build rapport
2. Answer questions
3. Share insider tips
4. Explain unwritten rules

**Topics to Cover:**
- Best lunch spots (if on-site)
- Team dynamics
- How to navigate the company
- Who to go to for what
- Common mistakes to avoid
- Success tips

**Mentor Action Items:**
- Schedule weekly 1:1s
- Share helpful resources
- Connect on Slack
- Offer to be first point of contact

**Expected Result:** Intern has a trusted guide

---

#### Step 2.6: Department Overview

**Who:** Department Head or Manager  
**When:** Day 1, 1:00 PM  
**Time:** 45 minutes

**Presentation Topics:**
1. Department Mission & Goals
2. Current Projects & Priorities
3. Team Structure & Roles
4. Key Processes & Workflows
5. Tools & Technologies Used
6. How Intern Will Contribute
7. Success Metrics
8. Q&A

**Expected Result:** Intern understands department context

---

#### Step 2.7: Review Role Track & Learning Plan

**Who:** Hiring Manager  
**When:** Day 1, 2:00 PM  
**Time:** 45 minutes

1. Open Intern Portal together
2. Navigate to **My Learning Plan**
3. Review role track:
   - Program duration
   - Learning modules
   - Required skills
   - Deliverables
   - Evaluation schedule

4. Review assigned tasks:
   - Onboarding tasks
   - First week tasks
   - First month goals

5. Explain evaluation process:
   - Onboarding evaluation (Day 14)
   - Mid-term evaluation (Day 45)
   - Final evaluation (Day 90)
   - Ongoing feedback

6. Set first month goals:
   ```
   Goal 1: Complete all onboarding modules
   Goal 2: Shadow 3 team members
   Goal 3: Complete first project deliverable
   Goal 4: Attend all team meetings
   Goal 5: Provide feedback on onboarding experience
   ```

7. Answer questions

**Expected Result:** Intern knows expectations and learning path

---

#### Step 2.8: Set Up Development Environment (Technical Roles)

**Who:** Technical Lead or Mentor  
**When:** Day 1, 3:00 PM  
**Time:** 1 hour

**For Engineering Interns:**
1. Clone repositories
2. Install development tools
3. Set up local environment
4. Run application locally
5. Review code standards
6. Review Git workflow
7. Review PR process
8. Assign first "good first issue"

**For Other Technical Roles:**
- Design: Set up design tools, access design system
- Data: Set up database access, BI tools
- Product: Set up product management tools

**Expected Result:** Ready to start contributing

---

#### Step 2.9: First Day Wrap-Up

**Who:** Hiring Manager  
**When:** Day 1, 4:00 PM  
**Time:** 30 minutes

1. Check in with intern:
   - How are you feeling?
   - Any questions?
   - Any concerns?
   - What was most helpful today?
   - What was overwhelming?

2. Review tomorrow's schedule

3. Remind of key contacts:
   - Manager
   - Mentor
   - HR
   - IT

4. Assign homework (optional):
   - Read specific documentation
   - Watch training video
   - Complete online module

5. Celebrate first day! 🎉

**Expected Result:** Intern feels supported and excited

---

### PHASE 3: FIRST WEEK ACTIVITIES (Days 1-5)

#### Step 3.1: Daily Check-Ins

**Who:** Manager or Mentor  
**When:** Daily, Days 1-5  
**Time:** 15 minutes each

**Daily Check-In Format:**
```
1. How are you feeling today?
2. What did you work on yesterday?
3. What are you working on today?
4. Any blockers or questions?
5. Do you have everything you need?
```

**Log check-in notes in system:**
- Navigate to Intern Portal > [Intern Name] > Activity Log
- Click **Add Note**
- Record key points
- Flag any concerns

**Expected Result:** Intern feels supported, issues caught early

---

#### Step 3.2: Complete Onboarding Modules

**Who:** Intern (self-paced)  
**When:** Days 1-5  
**Time:** 4-6 hours total

**Required Modules:**
1. Company Culture & Values (30 min)
2. Security & Data Privacy (45 min)
3. Communication Best Practices (30 min)
4. Time Tracking & Expenses (20 min)
5. Role-Specific Training (2-3 hours)

**Intern Actions:**
1. Log in to Intern Portal
2. Navigate to **Learning Modules**
3. Complete each module
4. Pass quizzes (70%+ required)
5. System tracks completion automatically

**Manager Actions:**
- Monitor completion in dashboard
- Follow up if modules not completed by Day 5

**Expected Result:** All onboarding modules completed

---

#### Step 3.3: Shadow Team Members

**Who:** Intern + Team Members  
**When:** Days 2-5  
**Time:** 2-4 hours per day

**Shadowing Schedule:**
```
Day 2: Shadow senior team member (morning)
Day 3: Shadow peer (afternoon)
Day 4: Attend key meetings
Day 5: Shadow cross-functional partner
```

**Intern Actions:**
1. Schedule shadowing sessions
2. Prepare questions
3. Take notes
4. Log shadowing hours in time tracking
5. Submit shadowing reflection:
   - What did you learn?
   - What surprised you?
   - What questions do you still have?

**Expected Result:** Intern understands team workflows

---

#### Step 3.4: First Small Task

**Who:** Intern  
**When:** Days 3-5  
**Time:** 4-8 hours

**Manager Actions:**
1. Assign first real task (small, low-risk)
2. Provide clear instructions
3. Set reasonable deadline
4. Offer support

**Good First Tasks:**
- Fix documentation typo
- Update test case
- Research topic and present findings
- Create simple mockup
- Analyze small dataset

**Intern Actions:**
1. Review task in Intern Portal
2. Ask clarifying questions
3. Complete task
4. Submit deliverable
5. Request feedback

**Expected Result:** Intern completes first contribution

---

### PHASE 4: ONBOARDING EVALUATION (Days 6-14)

#### Step 4.1: Onboarding Evaluation Meeting

**Who:** Manager + Intern  
**When:** Day 14  
**Time:** 45 minutes

**Preparation:**
1. Manager reviews:
   - Module completion
   - Task completion
   - Attendance
   - Engagement
   - Questions asked
   - Feedback from team

2. Intern prepares:
   - Onboarding feedback
   - Questions
   - Initial impressions

**Meeting Agenda:**
1. How has your first two weeks been?
2. Review onboarding checklist completion
3. Discuss what's going well
4. Discuss challenges
5. Review first month goals
6. Answer questions
7. Provide feedback

**Manager Actions After Meeting:**
1. Log in to Intern Portal
2. Navigate to **Evaluations** > **Create Evaluation**
3. Select: **Onboarding Evaluation**
4. Complete evaluation form:
   ```
   Overall Onboarding Experience: [1-5]
   Technical Setup: [1-5]
   Team Integration: [1-5]
   Understanding of Role: [1-5]
   Engagement Level: [1-5]
   
   Strengths Observed:
   [Text]
   
   Areas for Development:
   [Text]
   
   Goals for Next 30 Days:
   [Text]
   
   Manager Comments:
   [Text]
   ```

5. Click **Submit Evaluation**
6. System sends copy to intern and HR

**Expected Result:** Onboarding evaluation completed, goals set

---

### PHASE 5: FIRST MONTH INTEGRATION (Days 15-30)

#### Step 5.1: Increase Responsibility

**Who:** Manager  
**When:** Days 15-30  
**Time:** Ongoing

**Manager Actions:**
1. Assign more substantial tasks
2. Include intern in project planning
3. Invite to client/stakeholder meetings
4. Encourage independent work
5. Provide regular feedback

**Intern Actions:**
1. Take on more responsibility
2. Ask for stretch assignments
3. Seek feedback proactively
4. Build relationships across team
5. Start contributing to team goals

**Expected Result:** Intern is productive team member

---

#### Step 5.2: First Month Check-In

**Who:** Manager + Intern  
**When:** Day 30  
**Time:** 30 minutes

**Discussion Topics:**
1. Review first month accomplishments
2. Discuss challenges overcome
3. Identify learning opportunities
4. Set goals for next month
5. Discuss career interests
6. Plan for mid-term evaluation

**Manager Actions:**
1. Update intern profile with progress notes
2. Adjust learning plan if needed
3. Schedule mid-term evaluation (Day 45)

**Expected Result:** Clear plan for next phase

## 8. SUCCESS METRICS

Measure onboarding success by:
- Module completion rate (target: 100% by Day 5)
- First task completion (target: by Day 7)
- Onboarding satisfaction score (target: 4.0+/5.0)
- Manager satisfaction with onboarding (target: 4.0+/5.0)
- Time to first meaningful contribution (target: < 14 days)
- Retention through first 30 days (target: 100%)

---

## 9. TROUBLESHOOTING

| Issue | Solution |
|-------|----------|
| Intern doesn't receive welcome email | Check spam folder, resend from system |
| IT accounts not working | Contact IT immediately, use temporary access |
| Mentor unavailable | Assign backup mentor temporarily |
| Intern seems overwhelmed | Reduce initial workload, increase check-ins |
| Intern not engaging | One-on-one conversation to understand concerns |
| Manager not prepared | HR steps in, provides onboarding support |
