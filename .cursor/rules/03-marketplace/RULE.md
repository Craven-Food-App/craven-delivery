Crave'n is a three-sided marketplace:
- Merchants (restaurants / stores)
- Drivers (independent contractors)
- Customers

Rules:
- Marketplace incentives must be explicit in logic
- Fees, commissions, and payouts are first-class concerns
- Time, distance, and availability matter in every delivery flow

Never oversimplify:
- Pricing
- Driver assignment
- Order lifecycle states

If logic touches money, treat it as critical-path code.
