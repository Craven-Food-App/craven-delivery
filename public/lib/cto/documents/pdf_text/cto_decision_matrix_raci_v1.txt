4. RULES OF ENGAGEMENT

CTO must escalate to CEO when:

- System downtime or performance changes materially

- Security breach or vulnerability risk emerges

- Infrastructure cost exposure identified

- A decision impacts multiple departments

CTO holds independent authority over:

- Engineering standards

- System architecture

- Security controls

- Technology tool selection

- Infrastructure provisioning
